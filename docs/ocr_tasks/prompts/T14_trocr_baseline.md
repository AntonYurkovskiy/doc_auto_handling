# T14. Бейзлайн: нынешний TrOCR на новых кропах

## Зачем

Точка отсчёта из плана: «нынешний TrOCR, но уже на новых кропах». Задача показывает,
сколько дала одна правильная нарезка, и с чем сравнивать CNN из T16.

## Что сделать

1. **Модель.** Та же, что в приложении: `kazars24/trocr-base-handwritten-ru` через
   `TrOCRProcessor` + `VisionEncoderDecoderModel` (см. `app/services/voucher_trocr.py`).
   `trocr_image` возвращает только top-1, поэтому для beam search пиши обёртку
   в `ocr_lab/baseline_trocr.py` с тем же процессором. Код приложения не меняй.
2. **Два варианта подготовки кропа:**
   - «как есть», то есть ресайз в квадрат, как сейчас в приложении;
   - «с полями»: дополнить кроп белым до квадрата с сохранением пропорций.
3. **Инференс** на `val` и `test` из манифеста, по всем 17 подполям.
   - Beam search с `num_return_sequences=5`. Оценки последовательностей переведи
     в псевдовероятности через softmax по top-5.
   - Текст → число: оставить цифры; минимальные замены похожих символов (`O→0`, `l/I→1`,
     `S→5`). Пустой результат — это отсутствие предсказания.
4. **Окружение.** `.venv-train` с GPU, если T05 выполнена, иначе CPU. Оцени время заранее
   на 50 кропах. Если CPU-прогон длиннее 9 минут, делай его частями с дозаписью в JSONL.
5. **Выход и оценка.** Предсказания в формате T13:
   - `data/ocr/models/trocr_baseline/{val,test}_<вариант>.jsonl`;
   - оценка через `python -m ocr_lab.evaluate`.

## Критерии приёмки

- Отчёты оценки для обоих вариантов подготовки есть на `val` и `test`.
- В журнале таблица: точность по частям (день, месяц, часы, минуты, номер) и
  по ваучеру целиком, для двух вариантов.
