# T12. Разметка «напечатано / от руки»

## Зачем

План требует считать метрики отдельно для печатного и рукописного. Из плана:
- год напечатан на всех бланках, месяц почти всегда тоже;
- день и номер ваучера бывают напечатаны (179k, 64p), а бывают написаны от руки;
- в 1k от руки написан даже месяц.

Разметка нужна для метрик (T13) и для разбора ошибок. Модель учится на всех кропах.

## Что сделать

1. **Что размечать.** Для каждого скана — три метки: `voucher_number`, день и месяц.
   Бери `left_base.day` и `left_base.month`: внутри одного ваучера способ записи обычно
   одинаковый. Проверь это на выборке из 30 ваучеров по всем четырём строкам.
2. **Предсортировка, чтобы листы были однородными.** Простая эвристика печатности,
   например:
   - разброс толщины штриха;
   - доля почти горизонтальных и вертикальных сегментов;
   - корреляция с цифрами, отрисованными шрифтом бланка.
   Отсортируй кропы по ней и собери листы по 100 штук с индексами (`ocr_lab/sheets.py`).
3. **Разметка.** Посмотри листы и заполни `data/ocr/labels/printed_flags.csv`:
   `scan_id, group` (`voucher_number`, `day`, `month`), `kind` (`printed`, `handwritten`,
   `empty`, `unclear`). Удобно размечать блоками: «индексы 0–63 печатные, остальные
   рукописные, кроме …».
4. **Сверка** с метками `printed` из `data/ocr/review/truth_check.csv` (T04). Расхождения
   перепроверь.
5. **Статистика** в журнале: доля печатного по группе × буксиру × году.

## Критерии приёмки

- Метки есть для ≥ 98 % сканов с кропами. `unclear` ≤ 2 %.
- На выборке из T04 расхождение с проверкой T04 не больше 1 %.

## Отчёт

Журнал по шаблону. Код, если он появился (эвристика), коммитится в `ocr_lab/`, метки — нет.
Коммит: `OCR T12: разметка печатного и рукописного`.
