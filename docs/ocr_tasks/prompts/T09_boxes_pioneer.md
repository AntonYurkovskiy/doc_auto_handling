# T09. Боксы подполей: бланк Пионера и прочие варианты

## Зачем

У Пионера бланк другой: машинописный Courier, строки стоят в других местах (см. план
и отчёт T07). Готовой разметки для него нет совсем. Нынешняя вся сделана по 243k
(Коммунар). Формат макета и инструменты уже есть после T08: `app/ocr/layouts.py`,
`crop_subfields`, JSON в `app/ocr/layouts/`.

## Что сделать

Повтори процедуру T08 для всех вариантов, которые T07 нашла и которые ещё не размечены
(`pioneer_*` и прочие):

1. **Сетка и разметка.** Нарисуй сетку координат на `reference.png`, найди строки.
   Пропорции и подписи у Courier другие, поэтому координаты Коммунара не переноси
   механически. Нужны те же 17 боксов: `voucher_number` и по 4 части
   (`day`, `month`, `hour`, `minute`) для каждой строки.
2. **Проверка на 40 случайных сканах** варианта. Листы по каждому подполю, цель — 39 из 40
   целиком видны. Итерации — пока цель не достигнута.
3. **Отличия от Коммунара.** Отметь их в журнале: другой порядок элементов строки, иной
   формат месяца, где стоит номер.
4. **Ревизия Коммунара.** Если, работая с Пионером, заметишь общую проблему макета
   Коммунара, поправь его JSON и перепроверь на 20 сканах.

## Критерии приёмки

- Для каждого варианта из T07 есть JSON макета: 17 боксов, валидация проходит.
- В журнале таблица «вариант × подполе → видно целиком из 40».
- Проверки из `_common.md` зелёные.
