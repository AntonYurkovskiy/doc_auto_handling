# T28. Замкнуть цикл: подтверждённые ваучеры → переобучение → контроль

## Зачем

План, «Этап 6»:
- каждый подтверждённый ваучер становится новым обучающим примером, переобучение раз
  в месяц;
- следить за процентом автоприёма и правок;
- если точность просела в одном слоте, скорее всего, на буксире новый человек.

## Что сделать

1. **`ocr_lab/export_confirmed.py`.**
   - Выгружает из БД подтверждённые ваучеры: `confirmed_value` полей и путь к файлу скана.
   - Результат — таблица в формате манифеста с колонкой `source=app`.
   - Дубли с историей отсекаются по `sha256` и (буксир, год, номер).
2. **Сборка манифеста** (`ocr_lab/manifest.py`) умеет объединять историю и `source=app`.
   Правило сплита для ежемесячного цикла: последний полный месяц — holdout.
3. **`ocr_lab/retrain.py`** — один запуск на месяц:
   1. манифест;
   2. страницы и кропы (только новые);
   3. обучение digits и number тем же конфигом;
   4. калибровка и ONNX;
   5. приоры и веса декодера;
   6. сквозная оценка на holdout;
   7. сравнение «новая против текущей прод-модели».
   - Продвижение новой модели только если она не хуже по покрытию при целевой точности.
   - Версии лежат в `data/ocr/models/vYYYYMM/`. Переключение и откат — одна настройка
     (`APP_OCR_MODELS_DIR`) или файл-указатель `current`.
   - Каждый шаг идемпотентен. Долгие шаги поддерживают `--max-minutes` и `--resume`.
4. **Мониторинг** — `python -m ocr_lab.monitor --month YYYY-MM`, отчёт в markdown:
   - доля автоприёма;
   - доля правок оператором по полям, где предсказание ≠ подтверждению;
   - разрез по буксирам, по слотам вахт (формула из T23) и по вариантам бланка;
   - предупреждения: всплеск правок в одном слоте (возможно, новый человек); рост отказов
     выравнивания (возможно, новый бланк).
5. **Инструкция** в `docs/ocr_retrain.md`: как запускать ежемесячно, где смотреть отчёты,
   как откатить модель.

## Критерии приёмки

- Сухой прогон `retrain.py` на истории: holdout — последний месяц `test`, модели не
  продвигаются. Результат в журнале.
- Тесты на `export_confirmed` и на логику продвижения, на синтетике.
- Проверки из `_common.md` зелёные.
