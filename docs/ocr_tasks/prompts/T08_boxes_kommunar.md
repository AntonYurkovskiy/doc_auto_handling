# T08. Боксы подполей: бланк Коммунара

## Зачем

Главная находка плана: сейчас в TrOCR уходит вся строка
`«02» 07. 2026 г. Time 09 Hrs. 10 Min.` и сплющивается в квадрат 384×384. Нужны отдельные
кропы:
- `voucher_number`;
- для каждой из четырёх строк — `day`, `month`, `hour`, `minute`.

Всего 17 боксов на вариант. Год напечатан, его не режем.

## Что сделать

1. **`app/ocr/layouts.py`** — формат макета и загрузчик:
   - `Box`: `name` (например `left_base.hour`); `x0, y0, x1, y1` в пикселях эталона;
     `kind` (`two_digit` или `number`); `printed_by_template` (bool).
   - `Layout`: `variant`, `tug_code`, `ref_size`, `boxes`, `version`.
   - `load_layout(path)`, `load_layouts(dir)` и проверки: бокс внутри изображения, имена
     из списка, нет дублей.
   - `crop_subfields(warped, layout, pad=...) -> dict[str, np.ndarray]` — можно вынести
     в `app/ocr/crops.py`.
   - Файлы макетов лежат в `app/ocr/layouts/<variant>.json` и коммитятся: координаты
     не являются данными.
2. **Разметка для каждого варианта Коммунара** из T07 (`kommunar_*`):
   1. Нарисуй на `reference.png` сетку координат: линии через 50 px с подписями. Посмотри.
   2. Подсказки: строковые регионы Коммунара есть в `DEFAULT_VOUCHER_REGIONS`
      (`app/services/voucher_template.py`) и в `data/historical/predict_ocr/ocr_regions.txt`.
      Где что стоит в строке:
      - день — внутри «…»;
      - месяц — после закрывающей кавычки;
      - часы — между `Time` и `Hrs.`;
      - минуты — между `Hrs.` и `Min.`.
   3. Предложи боксы, нарисуй наложение, посмотри, поправь. Повторяй, пока не станет точно.
3. **Проверка на реальных сканах.**
   - Выровняй 40 случайных сканов варианта: разные годы, есть и печатный, и рукописный
     день и номер (см. T04).
   - Нарежь кропы и собери лист по каждому подполю.
   - Цель: значение целиком внутри бокса хотя бы в 39 из 40 сканов.
   - Рукописные цифры вылезают за линию и заходят на печатные подписи. Поэтому поля нужны
     с запасом (15–25 % высоты цифры), но без цифр соседнего подполя.
   - Повторяй, пока цель не достигнута.
4. **Наложение** итоговых боксов на эталон сохрани в
   `data/ocr/layouts/<variant>/boxes_overlay.png`, листы — в `data/ocr/sheets/`.

## Тесты

`tests/ocr/test_layouts.py`:
- загрузка и валидация JSON;
- `crop_subfields` на синтетическом выровненном изображении: форма кропа, отступы,
  обрезка у края.

## Критерии приёмки

- В `app/ocr/layouts/` есть JSON для каждого варианта Коммунара, 17 боксов в каждом.
- В журнале — таблица «подполе → сколько из 40 целиком видно».
- Проверки из `_common.md` зелёные.
