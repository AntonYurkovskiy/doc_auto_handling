## 5. Пропуски

1. **Транскрипты `.jsonl` T17–T20 в этом контейнере отсутствуют.** В `~/.claude/projects/` есть один каталог `-home-user` с единственным файлом — транскриптом текущей сессии (≈ 360 КБ, изменён 2026-10-10 18:18) и `ccr-tip.json`; каталога `subagents/` нет. Сессии T17–T20 шли в других временных контейнерах, их файлы сюда не попали.
2. **Чем заменено.** Метаданные облачных сессий через API аккаунта: итоговый `usage` и `cost_usd`, события `result` и `rate_limit_event`. Это данные платформы, а не файлы транскриптов. Дедупликация по `message.id` к ним неприменима: суммы уже агрегированы платформой.
3. **Не собрано (нужен разбор содержимого сообщений):** число ассистентских сообщений, число вызовов инструментов, число чтений картинок (png/jpg), записи `api_retry` / `api_error` в `system`-событиях. Для этого надо вытянуть в контекст все сообщения сессий (порядка сотен тысяч токенов на сессию вместе с кодом и путями), что противоречит правилу «только агрегаты». Вместо сообщений даны ходы (`num_turns`). Если эти метрики нужны, лучше снять их с самих транскриптов на машине, где они лежат (`collect_stats.py` умеет).
4. **Effort первой сессии T19** в метаданных не указан («нет данных»). Остальные: T17 high, T18 high, T19-доделка xhigh, T20 high. Модель T18 — `claude-sonnet-5-5` (Sonnet 5.5), в шапке промпта указан `claude-sonnet-5`.
5. **Цены.** Прайс «Sonnet 5» применён к Sonnet 5.5: контроль по `cost_usd` платформы сходится до $0,002 (разница — входные токены). Haiku 5.5 в прайсе из задания нет: цена неизвестна, дан только `cost_usd` платформы.
6. **Неделя.** Шаг `utilization` — 1 пункт, поэтому «0,36 → 0,36» означает «меньше 1 пункта», а не «ровно 0». Для T20 есть одна отметка (в начале сессии), хвост 16:28–16:55 отметками не покрыт.
7. **Время в `PROGRESS.md`** по T17–T20 не записывалось, а полей «расход» там нет; сравнить журнальное время с телеметрией нельзя. Даты в журнале совпадают с датами сессий.
8. **Вне выборки** (не задачи T17–T20): сессия планирования 29.09–01.10 ($28,97), облачные T06 ($1,96) и T13 ($2,05) от 29.09, две сессии Haiku.

## 7. Как считалось

- $ = cache_read × 0,20 + output × 20 + cache_write × 8 для Opus и × 0,20 / 10 / 4 для Sonnet, на миллион токенов. T20 считан по токенам Opus (176 input, 133 797 output), токены Haiku вынесены.
- Контроль: цена платформы `cost_usd` отличается от пересчёта на стоимость входных токенов ($4 за млн у Opus, $2 у Sonnet по самим цифрам платформы), не более $0,01 на сессию.
- Итоговый `usage` сессии (`list_sessions`) равен сумме `usage` ходов; кумулятивный `modelUsage` последнего `result` у T17 и T18 выше на ≈ $0,06 (запросы при возобновлении). В таблицах использован `usage`, `modelUsage` — только для хвостов.
- События читались `list_events` с фильтром `result` и `rate_limit_event` до начала каждой сессии; содержимое сообщений в файл не переносилось.
