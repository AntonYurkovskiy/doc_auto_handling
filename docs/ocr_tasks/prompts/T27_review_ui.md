# T27. Карточка ваучера: быстрая проверка оператором

## Зачем

Ваучеры ниже порога уверенности уходят в интерфейс проверки с кнопками top-3 (план,
«Этап 3»). Цель — чтобы оператор проверял ваучер за секунды, а не перепечатывал его.

## Что сделать

1. **`app/web/templates/voucher_form.html`.** Для полей `voucher_number` и четырёх
   datetime:
   - **Кропы подполей рядом с полем ввода:** номер; для строки — день, месяц, часы, минуты.
     Оператор видит рукопись, не открывая весь скан.
   - **До трёх кнопок-кандидатов** из `topk` с вероятностью. Клик подставляет значение
     в поле. Без внешних JS-библиотек: минимальный inline JS в стиле проекта.
   - **Подсветка уверенности**: высокая, средняя, низкая. Пороги — из настроек.
2. **Плашка уровня ваучера** с `ocr_status` и `ocr_confidence`: «Распознано уверенно»,
   «Нужна проверка» или «Распознавание недоступно».
3. **Список `/vouchers`:** колонка уверенности и фильтр «нужна проверка» / «уверенно».
4. **Отдача кропов.** Роут вида `/vouchers/{id}/crops/{subfield}`. Отдаёт файлы только
   из разрешённого каталога, через `resolve_stored_file` из `app/services/voucher_files.py`.
   Защита от `..` и посторонних имён подполей.
5. **Клавиатура.** Tab по полям; например Alt+1, Alt+2, Alt+3 выбирают кандидата поля
   в фокусе. Реализуй, если это не усложняет шаблон.
6. **Тесты** в `tests/test_web_vouchers.py`:
   - карточка рендерится с `topk` и без него;
   - роут кропов отдаёт файл и отказывает на обход каталога;
   - фильтр списка работает.

## Критерии приёмки

- Карточка без предсказаний OCR выглядит и работает как раньше.
- Проверки из `_common.md` зелёные.
- В журнале — описание сценария проверки оператором по шагам.
