# C1. Пакет «кропы цифр + метки» для облачных сессий

Выполняется **на ПК**, запуск через `claude -p`. Запускать только если владелец ответил
«да» на вопрос Q6 в `docs/ocr_tasks/DECISIONS.md`. Иначе заверши со статусом
«заблокировано».

## Зачем

Вариант А из `docs/ocr_tasks/cloud_alternative.md`: полные сканы остаются на ПК, а в облако
уходят только кропы цифровых подполей и метки. Облачные сессии на них учат модели и
декодер (T13, T15–T20, T22, T25).

## Что сделать

1. **`ocr_lab/cloud_bundle.py`**, запуск `python -m ocr_lab.cloud_bundle build --out data/ocr/cloud_bundle`:
   - **`crops/<subfield>/<scan_id>.png`** — 17 подполей: 4 строки × (день, месяц, часы,
     минуты) и номер. Только `align_ok`. Никаких других регионов бланка.
   - **`labels.csv`** — только эти колонки:
     - `scan_id, split, tug_code, year, variant`;
     - `left_base_dt, arrived_base_dt, started_work_dt, finished_work_dt`;
     - подполя истины `<row>_<part>`, `voucher_number`, флаги `has_hour24` и
       `crosses_midnight`;
     - `pair_id`;
     - `printed_*` (T12);
     - `app_offset_min` — отклонение начала работ от времени заявки в минутах, вместо
       самого времени заявки;
     - `work_type`, нормализованный.
     **Без** судна, агента, имён файлов заявок и путей.
   - **`README.md` пакета:** что внутри, дата сборки, хэш манифеста, правила: не
     переслать, удалить после работ.
2. **Проверка обезличенности.**
   - Автоматически: в `labels.csv` нет колонок и строк из запрещённого списка — судно,
     агент, путь, email.
   - Глазами: лист из 100 случайных кропов каждого подполя. Ни на одном не должно быть
     названий, подписей и печатей. Если бокс захватывает соседний печатный текст —
     обрежь или замаскируй поля кропа и перепроверь.
3. **Архив** `data/ocr/cloud_bundle.zip` и его размер в журнал. Куда его загрузить
   (приватный репозиторий данных или Object Storage), решает человек. Сам ничего
   не загружай.

## Критерии приёмки

- В пакете столько кропов, сколько `align_ok`-строк в `crops_index.csv` по этим подполям.
- Проверка обезличенности пройдена, листы посмотрены.
- Код и тест `tests/ocr/test_cloud_bundle.py` (синтетика: запрещённые колонки не попадают
  в пакет) закоммичены. Пакет — нет.
