Состояние на 2026-10-02: выполнены T00, T01, T02, T03, T04, T06, T07. Обновлять после
каждой завершённой задачи: `python docs/ocr_tasks/collect_stats.py` пересоберёт
`calibration/runs.csv` из логов `data/ocr/logs/*.jsonl`, а выводы ниже правятся вручную.

**Как читать цифры.**
- «Окно 5 ч» и «неделя» — `utilization` из `rate_limit_event` (доля, 0,18 = 18 %).
- Они общие для всего аккаунта, поэтому включают и разговоры в чате в те же часы. Цифры
  завышены на неизвестную величину, поэтому ниже они даны как оценки сверху.
- Часы ПК переводились вручную, поэтому длительность взята из `duration_ms` события `result`,
  а не из времени файлов. Для оборванных сессий длительность по часам ненадёжна.
- «Ходы» — `num_turns` из `result`. Сообщений ассистента примерно вдвое больше. Лимит
  `--max-turns` на практике нестрогий (T04: 178 ходов при лимите 150, T00: остановка на 81
  при лимите 80).
- Выборка маленькая (7 завершённых запусков, 5 задач): это ориентиры, а не законы.

| M · Sonnet high | 20–40 мин | 23 мин | ×1 |

Правило: задачи на Opus с просмотром картинок и ручной сверкой (T04, T08–T10) считать в 3–5

К чистому времени прибавлять запас на прерывания ×1,4.

Правило: `max_turns` в шапке не меньше 150 для любой задачи. Реальная защита от затрат —

## 7. Рекомендации

Для запуска:
1. Критерий готовности — запись `Статус: готово` в `PROGRESS.md` и коммит `OCR Tnn:`
   (раннер так и считает).
2. После перезапуска не удалять недописанные файлы: сессия продолжит с них.
3. Ключ `--max-tasks 1` для первой задачи нового класса: даёт замер до остального.

Для раннера (в порядке пользы):
1. Сторож: если дочерний `claude`/`devin` завершился или лог молчит дольше N минут, раннер
   завершает сессию и останавливает очередь, а не висит.
2. Автопоиск свежего `claude.exe` (в `%APPDATA%\Claude\claude-code\<версия>\<хеш>\`).
3. Один автоматический повтор при `authentication_failed`.
4. Печатать в сводке число сегментов и общий расход по `result`, а не только последний.

Для промптов и шапок:
1. `max_turns` не ниже 150, остальное ограничивать `--budget`.
2. Для задач с картинками указывать в шапке ожидаемое время ×3.
3. Тяжёлые зависимости ставить заранее по `SETUP_DEPS.md`, чтобы сессия не тратила часы
   на скачивание.
