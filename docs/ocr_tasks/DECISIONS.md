## Вопросы

Ответ пишите после стрелки. «По умолчанию» — что задачи делают без ответа.

**Q1. Минуты.** Их пишут кратно 10 или округляют при вводе в программу?
- По умолчанию: мягкий приор «кратно 10» (99,8 % истины). Уточнит T04.
- → да, стараются писать кратно 10 — принимаем как правило (минуты не кратные 10 — сильный штраф, не запрет).

**Q2. Полночь.** Как её пишут на бланке: `24:00`, `00:00`, `0:00`?
- По умолчанию: декодер допускает `24:00` только с минутами 00. Уточнит T04.
- → на практике скорее напишут 24:00, чем 00:00 новых суток.

**Q3. Автоприём.** Автопринятый ваучер сразу получает статус `confirmed` или только
предзаполняется с пометкой «высокая уверенность»?
- По умолчанию: только предзаполнение (`APP_OCR_AUTO_CONFIRM=false`).
- → только предзаполнение (`APP_OCR_AUTO_CONFIRM=false`).

**Q4. Целевая точность** среди автопринятых ваучеров.
- По умолчанию: 99,5 %.
- → да, 99,5 %.

**Q5. Картинки в облачные модели при разработке.** Можно ли показывать модели Claude
кропы и полосы сканов (T04, T07–T12, T16, T21)? Изображения уходят в API Anthropic.
Прод при этом остаётся локальным.
- По умолчанию: разрешено.
- При «нет» задачи готовят листы для человека и сами их не смотрят.
- → кропы (подполя, строки дат, номер) показывать можно; весь документ целиком — нет.

**Q6. Облако для данных.** Можно ли хранить обезличенные кропы цифр (без названий судов,
агентов и подписей) в приватном репозитории или хранилище? Нужно только для облачного
варианта, см. `cloud_alternative.md`.
- По умолчанию: нет.
- → да, только обезличенные кропы.

**Q7. Сплит по времени.**
- По умолчанию: `train` — до 2026-03-31, `val` — 2026-04…05, `test` — с 2026-06.
- → да, так.

**Q8. Эталоны бланков в git.** Статичные эталоны получаются медианой сканов и содержат
только форму бланка. Их можно коммитить в `app/ocr/layouts/`, чтобы приложение не
зависело от `data/`.
- По умолчанию: не коммитить, лежат в `data/ocr/layouts/`.
- → можно коммитить (эталоны — только форма бланка, без данных).
