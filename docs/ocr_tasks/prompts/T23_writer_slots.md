# T23. Слоты вахт и почерк — проверка гипотезы

## Зачем

План, «Этап 4»:
- бланки заполняют одни и те же люди: на Коммунаре 6 человек, на Пионере 8;
- график — сутки через трое, вахта меняется в 09:00;
- слот = ⌊(время выхода − 09:00) / 24 ч⌋ mod 4 для каждого буксира;
- пока состав не меняется, слот примерно равен человеку.

Гипотеза: в окне 1–2 месяца слот угадывается по почерку заметно лучше 25 %.
Если она подтвердится, автор = (буксир, слот, период).

Задача — эксперимент. В прод результат идёт только при выигрыше на временном тесте
после декодера (решает T24).

## Что сделать

1. **Слот каждого ваучера** по `left_base_dt`. Проверь распределение по слотам и что
   граница суток на 09:00 выглядит правдоподобно.
2. **Эмбеддинг почерка на уровне ваучера.**
   - Бинаризованные изображения **одной и той же цифры**. Какая это цифра, известно из
     истины: например, единицы часов и минут.
   - Для каждого ваучера — усреднённые признаки. Варианты, сравни 2 из них:
     - классические признаки автора: наклон, распределение толщины, contour-hinge;
     - признаки распознающей модели (бэкбон `digits_v1`). Это слабый вариант: модель учат
       игнорировать почерк;
     - DINOv2-small, если веса удастся скачать в `TORCH_HOME`.
3. **Проверка гипотезы.**
   - Для каждого буксира и скользящего окна в 1–2 месяца — kNN или логистическая
     регрессия по кросс-валидации: предсказать слот по эмбеддингу.
   - Сравни с шансом 25 % через перестановочный тест.
   - Отчёт по окнам.
4. **Если гипотеза подтвердилась:**
   - автор = (буксир, слот, период);
   - найди моменты смены состава: где точность слота резко падает.
5. **Если нет:**
   - кластеризация с k = 5–6 для Коммунара и 6–8 для Пионера;
   - по листу на кластер: 30 кропов, `data/ocr/sheets/writers/<tug>_<k>.png`, для человека
     в точке H4 (минут 15 на всё).
6. **Разбор ошибок v1 по авторам или кластерам.** Где сосредоточены ошибки, есть ли
   «трудные» авторы (например, «4», похожая на «Y», у автора 243k).

## Критерии приёмки

- Результат проверки гипотезы с p-value и цифрами по окнам.
- `data/ocr/labels/writer_slots.csv` с колонками `scan_id, tug, slot, period, cluster`.
- Выводы: имеет ли смысл T24.
