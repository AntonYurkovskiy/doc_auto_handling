# T15. Датасет и аугментации для CNN

## Зачем

План, «Этап 2»:
- небольшая CNN с двумя головами — десятки и единицы — плюс класс «пусто» для «9»
  вместо «09»;
- при 700 документах аугментации обязательны: поворот ±5°, сдвиг и масштаб кропа ±10 %
  (имитирует ошибку выравнивания), блюр, JPEG, толщина штриха, линия подчёркивания.

## Что сделать

1. **`ocr_lab/dataset.py`** — torch `Dataset` для двузначных подполей
   (`day`, `month`, `hour`, `minute` всех строк).
   - Источники: `crops_index.csv` и манифест. Берутся только `align_ok`, сплит — из манифеста.
   - **Цели:**
     - `units` — от 0 до 9;
     - `tens` — от 0 до 9 плюс 10 = «пусто»;
     - флаг `leading_zero_ambiguous` для значений < 10: на бланке может быть «09» или «9»,
       и истина этого не знает. Сама функция потерь — в T16.
     - `hour = 24` кодируется как tens=2, units=4.
   - **Вспомогательное:** `part_id` (день, месяц, часы, минуты), чтобы модель могла
     учитывать тип подполя; `scan_id` для разбора ошибок.
   - **Предобработка:**
     - серое изображение;
     - **без сплющивания**: вписать в 64×128 (H×W) с сохранением пропорций, фон белый;
     - нормализация. Точные размеры выбери по распределению размеров кропов и обоснуй.
   - Исключения: кропы из `crops_qc.csv` с проблемами и истина со статусом «ненадёжно»,
     если такой флаг есть.
2. **`ocr_lab/augment.py`** — cv2 и numpy, без albumentations, детерминированно по seed:
   - поворот ±5°, сдвиг и масштаб ±10 %, лёгкая перспектива;
   - Gaussian blur, JPEG качества 30–90;
   - эрозия и дилатация 1–2 px (толщина штриха);
   - яркость, контраст, гамма, шум;
   - синтетические линии подчёркивания и обрывки соседних печатных символов у краёв;
   - маленькое random erasing.
3. **Сэмплер** с балансировкой по `part_id`, чтобы минуты с 6 значениями не забивали
   дни с 31 значением. Балансировку по классам внутри подполя не делай: она сломает
   калибровку приоров.
4. **Синтетика (опция, выключена по умолчанию).** Двузначные числа, склеенные из цифр
   MNIST (около 11 МБ). Она закрывает редкие сочетания. Решать, включать ли её, будет T16
   по результату на `val`.
5. **Превью** `data/ocr/sheets/augment_preview.png`: 12 кропов × (оригинал + 8
   аугментаций). Посмотри и убедись, что аугментации не уничтожают цифры и не режут их
   за край. Если сессия не видит картинки — оставь это человеку и отметь в журнале.
6. **Тесты** `tests/ocr/test_dataset.py`:
   - кодирование целей для 0, 7, 10, 24, 31, 59;
   - вписывание без искажения пропорций;
   - детерминизм аугментаций по seed.

## Критерии приёмки

- Для каждого сплита в журнале: размер датасета по частям и распределение значений.
- Превью посмотрено, аугментации адекватны.
- Проверки из `_common.md` зелёные. Тесты с torch помечены так, чтобы в `.venv` без torch
  не падать: `pytest.importorskip("torch")`.
