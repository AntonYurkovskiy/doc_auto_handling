# T11. Запасной путь для сканов, которые не выровнялись

## Когда запускать

Только если по отчёту T10 неудачных выравниваний больше 5 %, или человек решил так
в точке H2 (`DECISIONS.md`). Иначе задачу пропускают.

## Зачем

План, «Этап 1»:
- запасной путь — якоря: значение лежит между `Time` и `Hrs.`, между `Hrs.` и `Min.`,
  внутри «…»;
- если больше 5 % сканов не выравниваются — YOLOv8n на ~150 листах с автоматически
  сгенерированными боксами.

## Что сделать

1. **Разбор отказов** из `data/ocr/reports/align_failures.csv`. Посмотри лист отказов и
   разложи их по типам: обрезан край, сильный изгиб или складка, тень, не тот документ,
   две страницы на скане.
2. **Путь А — якоря, пробовать первым.**
   - Шаблоны печатных подписей (`Time`, `Hrs.`, `Min.`, кавычки, `№`) вырежи из эталона
     каждого варианта.
   - После грубого аффинного выравнивания ищи их через `cv2.matchTemplate` в ожидаемой
     полосе каждой строки.
   - Боксы подполей строй относительно найденных якорей, отдельно для каждой строки.
     Такой подход переживает изгиб листа, при котором одна гомография не подходит.
3. **Путь Б — детектор, только если А не спасает большинство отказов.**
   - Обучающие метки бесплатны: у успешно выровненных сканов боксы из эталона
     переносятся на исходный скан (`map_points_to_scan`).
   - Лицензия важна:
     - Ultralytics YOLOv8 распространяется под **AGPL-3.0**; внутреннее использование
       обычно допустимо, но запиши это в «Вопросы к человеку»;
     - альтернатива с BSD-лицензией — `torchvision` Faster R-CNN MobileNetV3 или простой
       регрессор ключевых точек.
   - Инференс в проде — только через ONNX на CPU.
4. **Интеграция в нарезку.** В `ocr_lab/cut_crops.py` добавь запасной путь: вызывается,
   когда `align.ok=False`, и помечает кропы `method=anchors|detector`. Перережь отказы.
5. **Контроль.** Листы кропов, полученных запасным путём, по каждому подполю. Цель та же:
   значение видно целиком в ≥ 98 %.

## Критерии приёмки

- Доля сканов без кропов после запасного пути названа, по плану она должна стать < 2 %.
- Для прода есть функция в `app/ocr/`, без torch, которую позовёт `pipeline` (T25).
